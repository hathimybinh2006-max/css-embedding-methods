Luyện Tập 3 Cách Nhúng CSS Vào Trang Web

Cách 1: Inline Style

Tiêu đề sử dụng Inline CSS (Màu Đỏ)

Đây là đoạn văn bản được thay đổi màu sắc trực tiếp bằng thuộc tính style="color: #991b1b;" ngay trong thẻ <p>.

Cách 2: Internal Style

Tiêu đề sử dụng Internal CSS (Màu Cam)

Đây là đoạn văn bản được thay đổi màu sắc thông qua thẻ <style> đặt trong phần <head> của tài liệu HTML.

Cách 3: External Style

Tiêu đề sử dụng External CSS (Màu Xanh Dương)

Đây là đoạn văn bản được thay đổi màu sắc thông qua tệp tin CSS độc lập bên ngoài (style.css) liên kết bằng thẻ <link rel="stylesheet" href="style.css">.
