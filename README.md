# Thực Hành 3 Cách Nhúng CSS Vào Trang Web

Bài thực hành luyện tập nhúng CSS vào trang web HTML bằng các phương thức khác nhau.

## Nội dung bài tập

### 1. Phần 1: Inline Style (CSS trực tuyến)
- Định dạng màu sắc trực tiếp trên thẻ HTML bằng thuộc tính `style`.
- Ví dụ: `<h2 style="color: #dc2626;">...</h2>`

### 2. Phần 2: Internal Style (CSS nội bộ)
- Định dạng màu sắc thông qua thẻ `<style>` đặt trong phần `<head>` của trang web.
- Áp dụng thông qua các class `.internal-heading` và `.internal-paragraph`.

### 3. Phần 3: External Style (CSS ngoại tuyến)
- Định dạng màu sắc thông qua file riêng biệt `style.css` và liên kết bằng thẻ `<link rel="stylesheet" href="style.css">`.
- Áp dụng thông qua các class `.external-heading` và `.external-paragraph`.
